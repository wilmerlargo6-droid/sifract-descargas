# SIFRACT · Aplicación móvil

Aplicación móvil del sistema **SIFRACT**, de facturación de acueducto, alcantarillado y aseo de **Servimanantiales APC** (Cucaita, Boyacá).

> **Uso autorizado.** Esta aplicación es para el personal de Servimanantiales APC. Para entrar se necesita un usuario y una contraseña que entrega la administración; sin una cuenta no se puede usar.

## Instalar (Android)

1. Abre la sección **Releases** de este repositorio y descarga el archivo `sifract.apk` de la última versión.
2. Ábrelo en tu celular. Si Android lo pide, permite instalar aplicaciones de esta fuente.
3. Abre SIFRACT e inicia sesión con tu usuario.

## ¿Eres suscriptor y quieres ver tu factura?

No necesitas la aplicación ni una cuenta. Consulta y descarga tu factura en línea:

**https://sifract.onrender.com**

## Soporte

Si tienes problemas con tu usuario o con la instalación, comunícate con la administración de Servimanantiales APC.
